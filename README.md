## Features
* Futuristic Dark & Cyber Aesthetic: Glassmorphism UI cards, soft neon glows (`#00E5FF`, #7B61FF, `#00FFC6`), and custom blur lighting.
* Interactive 3D Hero Scene: Powered by Three.js featuring responsive lighting, floating geometric compositions, and mouse parallax.
* Advanced Animations & Interactions: Integrated GSAP, Lenis Smooth Scroll, Vanilla-Tilt 3D card hovering, and custom magnetic buttons.
* Responsive Across Devices: Fully optimized for Ultra-Wide desktops, Laptops, Tablets, and Mobile screens.

## Quick Start
1. Clone or download the repository files (`index.html`, style.css, `script.js`).
2. Open index.html in any modern web browser or serve via a local development server (e.g., VS Code Live Server).
